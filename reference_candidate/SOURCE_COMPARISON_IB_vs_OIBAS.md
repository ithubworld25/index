# Сравнение источников механики: IB v0.4 и OIBAS v1.0.1

## Резюме

Кандидат не копирует одну из версий целиком.

```text
IB v0.4 mechanics
+ OIBAS v1.0.1 theme and dynamic identifiers
+ new issue taxonomy
+ behavioral conformance tests
```

## Что подтверждено прямым сравнением START.html

| Область | IB v0.4 | OIBAS v1.0.1 | Решение rc1 |
|---|---|---|---|
| Групповой выбор | накопительный | накопительный | единый Set |
| Индивидуальный выбор | есть | есть | сохранить |
| Карточки при фильтре | только активные метки | только активные метки | сохранить |
| Клик без фильтра | все общие компетенции | компетентностные линии не строятся | IB |
| Клик с фильтром | только активные общие | только активные | IB + F-02 |
| Связи внутри семестра | исключены | возможны | запретить |
| Геометрия линий | внешние стороны, слева направо | центры карточек, прямые линии | IB |
| Несколько общих компетенций | параллельные линии | упрощённо | IB |
| Толщина по коэффициенту | да | фиксированная | IB |
| Глобальная линия компетенции | ближайший следующий узел | все пары соседних семестров | IB |
| Каталог | жёсткие числовые диапазоны 43 компетенций | строковые ID и динамические группы | OIBAS-модель, без названий в ядре |
| Семантика Soft | условие по имени группы | условие по имени группы | профиль relation_semantics |
| Реестр проблем | динамический, контекстный | преимущественно статический | IB + новая таксономия |
| Soft-дефицит | existing/candidate nodes | ограниченный контекст | IB |
| Shared editing | все БР по shared_key | поиск в текущей БР | IB |
| Повторная валидация | полный динамический пересчёт | частичный | IB |
| Сессия | глубокая, но зашиты роли/каталог | динамичнее, слабая совместимость | новая schema v2 |
| Тема | недостаточный контраст части текста | улучшенная светлая/тёмная тема | OIBAS |
| FIT | прокрутка/неполный FIT | компактный режим | реальный масштаб |
| Самопроверка | наличие данных/функций | наличие данных/функций | реальные сценарии |

## Что не переносится

- фиксированное число 43 компетенции;
- фиксированные группы internal/soft/ok/pk в JavaScript-условиях;
- предметные ошибки и несовершенства импорта обеих сборок;
- полная попарная сетка связей;
- статический реестр, не реагирующий на новые нарушения;
- изменение общей реализации только в текущей БР;
- декларативная самопроверка по наличию функций.

## Что создаётся заново

- профильная семантика групп;
- четыре независимых типа проблем;
- раздельные type / priority / status;
- совместимая переносимая сессия;
- реальные тесты F-02, shared editing, issue navigation и контраста;
- контроль неизменяемого ядра после фиксации v1.0.
