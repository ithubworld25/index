# TRAJECTORY_FUNCTIONAL_REFERENCE v0.9-rc1

Кандидат исполняемого эталона функциональной механики визуализации образовательной траектории.

## Назначение

Пакет предназначен для командной приёмки механики до фиксации версии `v1.0`. Это не финальная визуализация полного учебного плана и не предметный источник данных. В `START.html` используются сокращённые репрезентативные данные ИБ, достаточные для проверки двух бизнес-ролей, восьми семестров, общих и ролевых дисциплин, динамических групп компетенций, продолжений, методических нарушений, расхождений источников и неоднозначных сопоставлений.

## Архитектурное решение

Целевой эталон объединяет:

- функциональную механику `IB_Cyber_DevOps_v0.4`;
- темы и контрастность `OIBAS_v1.0.1`;
- динамический каталог компетенций и произвольное число групп;
- единый блок `Проблемы и расхождения`;
- исполняемые сценарии соответствия.

## Запуск

Распакуйте ZIP и откройте `START.html`. Интернет и сервер не требуются.

## Что проверять команде

Используйте `TEAM_ACCEPTANCE_SCENARIOS.md`. Кандидат не становится эталоном автоматически. После обратной связи выпускается `rc2` либо фиксируется `TRAJECTORY_FUNCTIONAL_REFERENCE_v1.0`.

## Ключевые правила

- Без активного фильтра клик на дисциплину показывает все её общие компетенции.
- При активном фильтре клик показывает только общие компетенции из активного набора и не сбрасывает фильтр.
- Каждая компетенция имеет отдельную цветную линию; Soft Skills пунктирные; продолжения серые.
- Каталог компетенций, группы, семантика линий и правила валидации приходят из профиля специальности.
- Тип проблемы, приоритет и статус — разные поля.
- Исправленные, неактуальные и нормализованные проблемы становятся серыми, но сохраняют историю.
- Редактирование локальное и поддерживает три области действия.

## Ограничения кандидата

- Данные сокращены и не предназначены для методической приёмки самой программы ИБ.
- Запись обратно в Excel отсутствует.
- Это кандидат ядра, а не универсальный импортёр всех вариантов Excel.
- Название панели проблем является параметром профиля и может быть изменено без изменения ядра.
