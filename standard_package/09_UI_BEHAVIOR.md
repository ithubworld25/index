# Стандарт поведения интерфейса

## Композиция

- Верхняя панель: название программы, учебный год, переключатель БР, FIT, тема, редактирование, рабочая сессия, экспорт, сброс.
- Панель фильтров: поиск, нулевые часы, продолжения, только нарушения, показать/снять все.
- Отдельная панель каждой группы компетенций с `Показать все`, `Выключить` и индивидуальными чекбоксами.
- Центральная карта: семестры слева направо.
- Правая панель: вкладки `Детали` и `Ошибки`.

## Карточки дисциплин

- Карточки создаются по стыковочному УП.
- Без активного выбора показываются все назначенные компетенции.
- При активном выборе показываются только выбранные компетенции, присутствующие в дисциплине.
- То же правило действует после клика на дисциплину.
- Карточка без активной компетенции остаётся на месте и приглушается.
- Нулевые часы отображаются приглушённо и могут быть скрыты.
- На карточке показываются название, код, фактические часы и метки компетенций с коэффициентами.
- Красный счётчик обозначает активные ошибки.
- Серый счётчик обозначает исправленные или неактуальные ошибки.

## Группы компетенций

Для каждой группы обязательны:

- `Показать все`;
- `Выключить`;
- индивидуальный переключатель каждой компетенции;
- постоянный цвет компетенции во всех БР;
- отображение выбранных меток на карточках;
- построение линий только для выбранного набора.

Группы не должны быть жёстко зашиты под одну специальность. Они определяются профилем программы.

## Линии

- Линии строятся только для активных компетенций.
- Цвет компетенции постоянен в пределах программы и между БР.
- Soft Skills отображаются пунктирными линиями мест оценивания.
- Продолжение дисциплины отображается нейтральной серой пунктирной линией.
- При фокусе дисциплины каждая общая активная компетенция строится отдельной параллельной линией своего цвета.
- Толщина линии может отражать коэффициент, но числовое значение также должно быть доступно в панели.

## Фокус дисциплины

После клика на дисциплину:

- сохраняется текущий фильтр компетенций;
- выделяется выбранная дисциплина;
- связанные дисциплины определяются только по активным компетенциям;
- каждая общая компетенция получает собственную линию;
- справа показываются выбранные компетенции;
- полный набор дисциплины доступен в раскрываемом блоке;
- показываются связанные дисциплины, источники и ошибки дисциплины.

## Ошибки

- Реестр и ошибки дисциплины используют одни и те же объекты данных.
- Каждая запись кликабельна.
- Клик переключает нужную БР, семестр, дисциплину или контекст и раскрывает диагностику.
- В диагностике обязательны: правило, текущее состояние, ожидаемое состояние, источники, роли, действие и статус.
- `Исправлена` и `Не актуальна` визуально серые, но логически различны.
- Ручное закрытие требует комментарий.
- Возврат нормализованной ошибки в работу доступен.
- Если правило проходит после редактирования, ошибка автоматически переводится в `Исправлена`.

## Редактирование

- Редактирование является локальной песочницей, а не прямой записью в Excel.
- Изменяются компетенции, коэффициенты, статусы ошибок и комментарии.
- Область действия выбирается явно: текущая реализация, общая реализация, все реализации канонической дисциплины.
- После изменения выполняется полный пересчёт.
- Доступны автосохранение, переносимая рабочая сессия, полный снимок и журнал изменений.

## Темы

- Доступны `Системная`, `Светлая`, `Тёмная`.
- Компетенция сохраняет смысловой hue.
- Тёмная тема использует отдельные высококонтрастные токены.
- Цвет не является единственным носителем смысла.
