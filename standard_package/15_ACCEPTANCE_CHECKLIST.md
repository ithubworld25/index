# Чек-лист приёмки визуализации

## Изоляция и источники

- [ ] Входной манифест содержит только файлы текущего чата.
- [ ] Предметные данные других специальностей не использованы.
- [ ] Карта построена по стыковочному УП.
- [ ] Матрица используется для компетенций и коэффициентов.
- [ ] ФГОС используется как нормативный контур и источник продолжений.
- [ ] Все расхождения зафиксированы, а не исправлены молча.

## Данные

- [ ] Разделены канонические дисциплины и реализации.
- [ ] Сохранены ссылки на файл, лист, строку или ячейку.
- [ ] Коэффициенты только 1–4.
- [ ] Есть единый каталог компетенций и устойчивые цвета.
- [ ] Разбиения и объединения подтверждены словарём.
- [ ] Нулевые часы сохранены как отдельные узлы.

## Интерфейс

- [ ] Семестры расположены слева направо.
- [ ] Бизнес-роли переключаются.
- [ ] У каждой группы есть `Показать все` и `Выключить`.
- [ ] Индивидуальный выбор компетенций работает.
- [ ] Без выбора видны все метки.
- [ ] При выборе видны только активные метки.
- [ ] Фокус дисциплины не возвращает скрытые компетенции.
- [ ] Карточки без активных компетенций остаются и приглушаются.
- [ ] Soft Skills пунктирные.
- [ ] Продолжения дисциплин нейтрально-серые.
- [ ] Общие компетенции фокуса имеют отдельные цветные линии.

## Ошибки и редактирование

- [ ] Реестр ошибок кликабелен и переводит к точке карты.
- [ ] Ошибки дисциплины видны справа и кликабельны.
- [ ] Открытые ошибки имеют красный счётчик.
- [ ] Исправленные и неактуальные имеют серый счётчик.
- [ ] Ручное закрытие требует комментарий.
- [ ] Возврат ошибки в работу доступен.
- [ ] После редактирования выполняется пересчёт.
- [ ] Рабочая сессия сохраняется и загружается.
- [ ] Полный снимок и журнал изменений экспортируются.

## Темы и контраст

- [ ] Системная, светлая и тёмная темы работают.
- [ ] Контраст обычного текста не ниже 4.5:1.
- [ ] Контраст UI и крупного текста не ниже 3:1.
- [ ] Проверены muted, subtle, placeholder, disabled и серые статусы.
- [ ] Проверены метки компетенций на карточках.
- [ ] Проверены линии на фоне карты.
- [ ] Цвет не является единственным носителем статуса.

## Пакет

- [ ] `START.html` находится непосредственно в корне ZIP.
- [ ] HTML автономен, данные встроены.
- [ ] Нет внешних JS, JSON, CDN и `fetch()`.
- [ ] Inline JavaScript проходит синтаксическую проверку.
- [ ] Все JSON разбираются.
- [ ] Браузерный smoke-test проходит.
- [ ] ZIP целостен, пути безопасны.
- [ ] SHA-256 записан в протокол.
- [ ] Ссылка указывает на реально зарегистрированный файл или стабильный объект Google Drive.
