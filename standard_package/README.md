# STANDARD_TRAJECTORY_VISUALIZATION_v1.0

Универсальный стандарт воспроизводимого создания интерактивных визуализаций образовательных траекторий в разных чатах одного проекта.

## Назначение

Архив задаёт одинаковую механику интерфейса, приоритет источников, модель данных, методические проверки, статусы ошибок, редактирование, темы и состав финального пакета.

Он **не содержит предметных данных конкретной специальности**. Дисциплины, компетенции, часы и бизнес-роли для каждой новой визуализации берутся только из документов, прикреплённых в текущем чате и включённых во входной манифест.

## Как использовать

1. Прикрепите ZIP стандарта в корень проекта.
2. В новом чате прикрепите документы только одной специальности: УП ФГОС, стыковочные УП и матрицы компетенций.
3. Вставьте текст из `03_SHORT_LAUNCH_PROMPT_RU.txt`.
4. Ответьте только на блокирующие вопросы P0.
5. Получите автономную визуализацию в одинаковой структуре и единый проверенный ZIP.

## Основные файлы

- `00_MANIFEST.json` — состав и контрольные суммы пакета;
- `01_STANDARD_SPEC.json` — машиночитаемая спецификация;
- `02_FULL_GENERATION_PROMPT_RU.md` — полный производственный промпт;
- `03_SHORT_LAUNCH_PROMPT_RU.txt` — короткий пусковой промпт;
- `04_PROJECT_INSTRUCTION_SNIPPET.txt` — фрагмент инструкции проекта;
- `05_INPUT_CONTRACT.json` — требования к входам и P0;
- `06_SOURCE_PRIORITY_AND_MAPPING.md` — иерархия источников и сопоставление;
- `07_VALIDATION_RULES.json` — правила валидации;
- `08_DATA_SCHEMA.json` — нормализованная модель;
- `09_UI_BEHAVIOR.md` — обязательная механика интерфейса;
- `10_THEME_AND_CONTRAST.json` — светлая/тёмная тема и контраст;
- `11_FINAL_PACKAGE_CONTRACT.json` — состав финального ZIP;
- `12_PROGRAM_PROFILE_TEMPLATE.json` — профиль конкретной программы;
- `13_INPUT_MANIFEST_TEMPLATE.json` — манифест документов текущего чата;
- `14_DISCIPLINE_MAPPING_TEMPLATE.json` — словарь сопоставлений;
- `15_ACCEPTANCE_CHECKLIST.md` — проверка результата;
- `reference/UI_REFERENCE_SHELL.html` — нейтральный эталон композиции.

## Ключевые ограничения

- Стандарт задаёт механику, но не является источником предметных данных.
- Стыковочный УП формирует карту.
- Матрица задаёт компетенции и коэффициенты.
- УП ФГОС используется как нормативный контур и для подтверждения продолжений.
- Нельзя исправлять конфликты молча.
- Нельзя выдавать ссылку на файл до подтверждения его фактического создания и доступности.

## Тёмная тема

В стандарт включены усиленные токены контраста и обязательная проверка обоих режимов. Нормальный текст должен иметь контраст не ниже 4.5:1, крупный текст и управляющие элементы — не ниже 3:1.
