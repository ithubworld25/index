# Назначение UI reference shell

`UI_REFERENCE_SHELL.html` — нейтральный визуальный эталон компоновки и контрастности. Он не содержит данных конкретной специальности и не должен использоваться как источник дисциплин, компетенций или правил программы.

Эталон фиксирует:

- расположение верхней панели, групп компетенций, карты и правой панели;
- поведение меток при активном выборе;
- красные и серые счётчики ошибок;
- структуру карточки ошибки и карточки дисциплины;
- переключение системной, светлой и тёмной темы;
- базовые токены повышенного контраста.

Генератор новой визуализации должен воспроизводить механику, но наполнять её только данными текущего чата.

`MINIMAL_DEMO_DATA.json` предназначен только для технических тестов и не может использоваться как источник новой программы.
