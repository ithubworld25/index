# Контрольная приёмка стандарта v1.1

## Запуск

- `START.html` находится в корне ZIP.
- Файл открывается без интернета, сервера и дополнительных загрузок.
- Встроенная самопроверка завершена успешно.

## Темы

- Светлая тема читаема.
- Тёмная тема читаема во всех панелях.
- Цвет компетенции сохраняет смысловой оттенок между темами и БР.

## Компетенции

- Две группы можно включить одновременно.
- Выключение одной группы не сбрасывает вторую.
- Индивидуальные переключатели работают.
- Без выбора виден полный набор карточки.
- С выбором видны только выбранные метки.
- Карточки без выбранной компетенции приглушаются, но не исчезают.

## Выбор компетенции

- Все карточки с компетенцией выделены.
- Остальные приглушены.
- Компетентностные линии отсутствуют.
- Есть пояснение, что выделение не означает пререквизиты.

## Фокус дисциплины

- Без фильтра показаны все общие компетенции.
- С фильтром показаны только активные общие компетенции.
- Выбранная карточка выделена отдельно.
- Связанные карточки явно выделены.
- Несвязанные карточки приглушены.
- Одна компетенция создаёт одну отдельную линию.
- Линии входят и выходят с внешних сторон карточек.
- Внутри одного семестра компетентностных линий нет.
- Soft Skills пунктирные.
- Продолжения серые.
- Справа видны связанные дисциплины, компетенции и коэффициенты.
- Переход по связанной дисциплине работает.

## Бизнес-роли

- Переключение БР работает.
- Активные фильтры сохраняются.
- Общая дисциплина помечена числом БР.
- В деталях видны все БР, семестр и часы.

## Проблемы и расхождения

- Видны четыре типа проблем.
- Строка до раскрытия показывает смысл, объект/семестр, БР и статус.
- Карточка раскрывается непосредственно в месте клика.
- При выборе следующей проблемы диагностика и карта переключаются синхронно.
- Ручное закрытие без комментария блокируется.
- Статусы `Исправлена во внешнем источнике`, `Нормализована`, `Не актуальна` различимы.
- Возврат в работу работает.
- Нормализованные записи находятся в отдельной группе.
- Статусы сохраняются после обновления страницы.
- Экспорт и импорт статусов работают.

## Проблемы семестра

- В заголовке семестра виден счётчик.
- Существующие места и кандидаты визуально различаются.
- Кандидаты не получают счётчик ошибки.
- Режим `Только проблемы` сохраняет контекст семестровой проблемы.

## Навигация

- Поиск работает по названию и коду.
- Нулевые часы скрываются и возвращаются.
- FIT масштабирует карту.
- `Снять компетенции`, `Снять фокус`, `Сбросить выделение` работают раздельно.
- Повторный клик и Esc снимают фокус дисциплины.

## Техническая приёмка

- SHA-256 неизменяемого ядра совпадает.
- JavaScript проходит синтаксическую проверку.
- Все JSON валидны.
- Светлая и тёмная темы проходят браузерный smoke-test.
- ZIP целостен и не содержит небезопасных путей.
- Ссылка ведёт на реально зарегистрированный стабильный файл.
