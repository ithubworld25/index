# Примеры использования стандарта

## Новый комплект одной специальности

1. Прикрепите в новый чат УП ФГОС, стыковочные УП и матрицы компетенций только одной специальности.
2. Вставьте текст из `03_SHORT_LAUNCH_PROMPT_RU.txt`.
3. Ответьте только на вопросы P0.
4. Получите единый проверенный ZIP.

## Обновление учебного года

Передайте утверждённую версию прошлого года и копию нового года как отдельные входы. Во входном манифесте явно отметьте, какой год является источником визуализации, а какой — черновой копией. Система не должна смешивать их без явного правила.

## Несколько бизнес-ролей

Каждому стыковочному УП и каждой матрице назначьте `business_roles`. Общая реализация редактируется один раз только при подтверждённом `shared_key`; иначе изменения остаются локальными для конкретной реализации.

## Неполный комплект

Если нет стыковочного УП, это P0: карта не строится по матрице или ФГОС вместо него. Если есть стыковочный УП, но части строк матрицы не сопоставлены, визуализацию можно собрать, а несопоставленные строки вывести как кликабельные предупреждения.
